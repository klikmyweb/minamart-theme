# Minamart Theme

A premium, native WordPress WooCommerce theme for Fresh Fish & Seafood e-commerce.

## About Minamart

Minamart is a modern, fast, and user-friendly online seafood store built on WordPress and WooCommerce.

## Features

- ✅ Native WordPress WooCommerce Theme
- ✅ Mobile-First Responsive Design
- ✅ Premium UI with Soft Shadows & Animations
- ✅ WooCommerce Fully Integrated
- ✅ SEO Optimized
- ✅ Fast Loading & Performance Optimized
- ✅ Accessibility Ready
- ✅ No Page Builder Bloat
- ✅ No Bootstrap or Tailwind Dependencies
- ✅ Clean, Maintainable Code

## Requirements

- PHP 8.0+
- WordPress 6.0+
- WooCommerce 6.0+

## Installation

1. Download or clone this repository into `wp-content/themes/minamart-theme`
2. Activate the theme in WordPress Admin
3. Ensure WooCommerce plugin is installed and activated
4. Configure theme options and WooCommerce settings

## Theme Structure

```
minamart-theme/
├── style.css              # Main stylesheet
├── functions.php          # Theme setup
├── header.php             # Header template
├── footer.php             # Footer template
├── front-page.php         # Homepage
├── index.php              # Default template
├── page.php               # Single page
├── single.php             # Single post
├── archive.php            # Archive pages
├── search.php             # Search results
├── 404.php                # 404 page
├── inc/                   # PHP includes
├── template-parts/        # Template components
├── assets/                # CSS, JS, Images
└── woocommerce/           # WooCommerce templates
```
